DEEPDRAFT - FRIENDS PLAYTEST
Windows x86-64 - 2026-10-13 - version 0.1.0

START
Extract the entire ZIP into a folder, then run Deepdraft.exe.
Keep Deepdraft.pck beside the executable. Godot is not required.
This build uses DirectX 12 / Forward+ and needs a compatible graphics driver.
The initial world generation can take a little while.
For updates, extract into a new folder or close the game before replacing files.
Do not replace Deepdraft.pck while its game is running. Saves carry across builds.

FIRST STEPS
Open Colony on the bottom dock, choose Settlement flag, and found your colony.
The dock provides mining, gathering, stockpiles, crafting and furniture tools.
Menu > Save / Load saves and restores your settlement; saves are not loaded
automatically at launch. Menu > Audio adjusts ambience and effects separately.

CAMERA AND LAYERS
WASD or arrow keys: pan. Hold Shift for slower movement.
Middle mouse drag: pan. Right mouse drag: orbit. Mouse wheel: zoom.
Backslash: toggle the underground slice.
[ and ]: move the slice by one cell; Ctrl+[ and Ctrl+]: move one block.
The right-hand layer controls provide the same actions.
Escape closes menus or cancels the current tool.

SAVES AND BUG REPORTS
Saves: %APPDATA%\Godot\app_userdata\Deepdraft\saves
Log:   %APPDATA%\Godot\app_userdata\Deepdraft\logs\godot.log
Audio and window preferences are stored in the same Deepdraft user folder.
When reporting a problem, include what you were doing, a screenshot, the log,
and the affected save if possible. Note your Windows version and graphics card.
Deepdraft.console.exe runs the same game with a visible diagnostic console.

This is an early playtest of the colony foundation. Farming, brewing, trade
and combat remain future work. No player saves are included in this download.
